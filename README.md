# Aayu Printing Studio

Aayu Printing Studio is a full-stack AI-powered SaaS platform built to modernize the print ordering experience for both customers and print businesses. The platform combines a customer-facing storefront, secure account management, file upload workflows, order processing, and an intelligent AI assistant into a single scalable application. Designed as a production-grade software project, it demonstrates the complete lifecycle of building and deploying a modern SaaS product—from frontend development and backend architecture to authentication, database design, cloud integration, and artificial intelligence.

The application allows customers to explore print products, upload artwork, place orders, manage their account, and receive instant support through an AI-powered assistant trained on business-specific knowledge. Behind the scenes, the platform leverages a Retrieval-Augmented Generation (RAG) architecture powered by ChromaDB and Large Language Models to deliver accurate responses about products, pricing, printing requirements, and customer queries. Secure JWT authentication, role-based access control, PostgreSQL data storage, and scalable FastAPI services ensure that the platform is built with real-world production standards in mind.

Built using React, Vite, FastAPI, PostgreSQL, ChromaDB, and Groq LLMs, the project serves as a practical demonstration of modern SaaS engineering principles, including API development, state management, cloud databases, AI integration, secure authentication, file handling, and responsive user experience design. The system currently includes a complete marketing website, customer dashboard, shopping cart and checkout flow, file upload pipeline, AI-powered support assistant, knowledge-base search, and administrative foundations for future business operations.

This project represents a hands-on journey into software engineering, artificial intelligence, and SaaS architecture, with a strong focus on building production-ready systems rather than isolated features. Future development will include payment gateway integration, advanced analytics, containerized deployment, CI/CD automation, and additional enterprise-grade capabilities as the platform continues to evolve toward a fully deployable commercial solution.
